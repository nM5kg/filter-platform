Filter Platform — GeckoView prototype test pages

Serve this folder over HTTP (python3 -m http.server 8130 --bind 127.0.0.1) and open the pages in the Filter Browser. Every visual element must be covered (dark overlay, "Filtered — image covered") on first paint, because this prototype has no on-device detector yet — every finding is REVIEW, and REVIEW stays covered. The status line at the bottom of the browser shows the covered/allowed/blocked counts.

  1. 01 — HTML images (<img>, picture/srcset, lazy, data-src)
  2. 02 — CSS backgrounds (background-image, data-URI, sprite)
  3. 03 — Canvas 2D (drawImage person + landscape, animated video canvas)
  4. 04 — SVG (inline SVG with raster image, <img src="*.svg">)
  5. 05 — WebGL (textured quad with a person photo, procedural shader)
  6. 06 — Video frames (paused at 5 s, autoplaying loop, poster)
  7. 07 — Live streams (canvas.captureStream, optional camera)
  8. 08 — Dynamic content (added after load, src swaps, infinite scroll)

Assets are real photos/video from the scanner's labeled test set: assets/p1-huang-portrait.jpg (person), assets/d1-crowd-funeral.jpg (crowd), assets/l1-glacier-lake.jpg (landscape, no person), assets/obama-chile-480p.webm (Obama speaking, person in frame).

Expected result on every page in this prototype: everything visual covered, nothing allowed. If anything is visible uncovered, that is a filter failure — note which element and how it got through.
